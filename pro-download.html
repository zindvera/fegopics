How to Activate PRO

1

Upload PRO Plugin ZIP

Download the PRO plugin ZIP above. Go to your WordPress admin under Plugins → Add New → Upload Plugin, select the downloaded file, and click Activate Plugin.

2

Get License Code

Open ScrollStrike → Upgrade to PRO in your admin menu. Choose your plan option (1 Month, 6 Months, or 1 Year) in the PRO Plan Options section to get your license code on Gumroad.

3

Enter Key & Activate

On the Upgrade to PRO page, paste your license code into the input field and click Activate to unlock all PRO features instantly.
